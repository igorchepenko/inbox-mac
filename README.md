# Inbox для Mac

Личный таск-менеджер для macOS. Записываешь задачу за пару секунд по **⌥Space** из любого приложения, она падает в «На разбор», а раз в день ты разбираешь её: важность, проект, дата, напоминание.

- Главная со сводкой дня, списки На разбор, Сегодня, Скоро, Архив, Календарь и твои проекты.
- Данные лежат только на этом Маке, в SQLite: `~/Library/Application Support/com.igorchepenko.inbox/inbox.db`. Никакой синхронизации и облака.
- Напоминания приходят обычными уведомлениями macOS.
- Тема как в системе, или светлая и тёмная вручную: переключатель внизу боковой панели.

## Что нового в этой сборке (0.3.0)

- **Проекты стали пространствами.** Пункт пространства в левом меню залит его цветом, палитра ярче (40 цветов, есть чистый лимонный). Цвет пространства виден полоской и оттенком на задачах в списке, на канбане и в календаре.
- **Сортировка списков**: по дате и времени, по важности или по матрице Эйзенхауэра. Запоминается для каждого списка.
- **Канбан только по этапам**, три столбца: Новые, К выполнению, Готово. «На разбор» переименован в «Новые». Галочка в чекбоксе едва видна у открытой задачи и яркая у сделанной.
- **В строке списка** видны этап, дата, время, важность, квадрант и пространство.
- **Подсказки мгновенные**: длинное описание пространства, пункт чеклиста, ссылка и всё обрезанное многоточием показываются целиком при наведении. Пункт чеклиста ограничен тремя строками.
- **Панели**: левую и правую можно тянуть за край и сворачивать совсем.
- **Главная**: чёткая граница шапки вместо размытия, «Настроить главную» стала иконкой, описания пространств убраны.
- **Календарь**: пересекающиеся задачи стоят рядом колонками. В узкой колонке название идёт вертикально, полный текст в подсказке.
- Зона сброса файлов из Finder не мигает. Поиск пространства не показывает лишних совпадений.

## Что было в 0.2.0

- **Важность в 5 ступеней** с иконками как в Jira: две стрелки вниз, стрелка вниз, «=», стрелка вверх, две стрелки вверх. Иконка видна в списках, на канбане, в календаре и на главной. Клавиши 1–5. Старые задачи сдвинуты: низкая стала «низкой», средняя «средней», высокая «высокой».
- **Канбан** по умолчанию показывает этапы работы: Новые, К выполнению, В работе, Готово за 7 дней. Переключатель над доской даёт ещё группировку по сроку, важности (5 столбцов) и матрице Эйзенхауэра. Режим «карточками» убран.
- **Календарь**: клик по пустому месту создаёт задачу на это время на 30 минут и сразу открывает название для правки.
- **Задача**: ссылки отдельно от файлов, с названием (показывается как гиперссылка) и кнопкой копирования; длинные пункты чеклиста переносятся целиком; в выборе даты клик по месяцу открывает выбор месяца и года; зона сброса файлов из Finder видна целиком; новые цвета квадрантов матрицы.
- **Левое меню**: разделитель, сворачиваемая секция «Проекты», «+ Новый проект» сверху, поиск проекта по **⌘P**. Длинное описание проекта больше не ломает вёрстку.
- **Страница «Проекты»** (⌘6): все проекты карточками с описанием и сводкой по задачам.
- **Палитра проектов на 32 чистых цвета.**
- **Сочетания клавиш**: кнопка с клавиатурой внизу меню и в шапке списка открывает окно со всеми сочетаниями (или ⌘/). У кнопок с сочетанием оно показано в подсказке при наведении.
- **⌥Space**: в Настройки → Быстрый ввод есть кнопка «Проверить». Если сочетание перехватило другое приложение, Inbox покажет плашку и подскажет, что делать.
- **Внешний вид**: фон окна, меню и блоков разведены по яркости, статистика читается в тёмной теме. В настройках у каждого параметра подписано значение по умолчанию и есть кнопка сброса.
- Иконка «Молния» теперь и у пункта «Главная». Версия поднята до 0.2.0, чтобы Spotlight забыл старую иконку.

Есть два способа поставить приложение. Первый проще: скачать готовый файл, который собирает GitHub. Второй: собрать самому на Маке, он нужен, если хочешь запускать свежий код из ветки.

## Способ 1. Скачать готовое приложение (5 минут)

GitHub сам собирает приложение на своём Маке при каждом изменении в pull request и в `main`.

1. Открой в браузере https://github.com/igorchepenko/inbox-mac/actions (ты должен быть залогинен в GitHub).
2. Слева выбери **Build macOS app**. Справа нажми на верхний запуск с зелёной галочкой ✓. Если там жёлтый кружок, сборка ещё идёт, подожди около 15 минут.
3. Прокрути страницу запуска вниз до блока **Artifacts** и нажми **Inbox-macOS**. Скачается `Inbox-macOS.zip`.
4. Открой папку «Загрузки» в Finder и дважды кликни `Inbox-macOS.zip`. Появится файл `Inbox_0.3.0_universal.dmg`. Дважды кликни его.
5. Если старая версия Inbox уже стоит: выйди из неё (иконка в строке меню → «Выйти из Inbox»), удали `Inbox.app` из «Программ» в Корзину. Задачи не пропадут, они лежат отдельно.
6. В открывшемся окне перетащи иконку **Inbox** (белая молния на красной плитке) на папку **Applications**.
7. Приложение не подписано сертификатом Apple, поэтому macOS при первом запуске скажет, что оно «повреждено» или «не может быть проверено». Это нормально для самодельных приложений. Сними метку «скачано из интернета» одной командой:
   - нажми **⌘ Space**, набери `Терминал`, нажми Enter;
   - вставь команду и нажми Enter:
     ```bash
     xattr -cr /Applications/Inbox.app
     ```
   - Терминал ничего не ответит, это значит, что всё прошло успешно.
8. Открой Inbox через Launchpad или папку «Программы». Дальше смотри раздел «Что должно появиться на экране».

## Способ 2. Собрать самому

### Шаг 1. Открыть Терминал
Нажми **⌘ Space**, набери `Терминал`, нажми Enter. Все команды ниже вставляй туда по одной и нажимай Enter.

### Шаг 2. Инструменты разработчика Apple
```bash
xcode-select --install
```
- Если появится окно «Установить инструменты разработчика», нажми **Установить**, затем **Принять**. Установка идёт 5–15 минут.
- Если Терминал ответит `command line tools are already installed`, они уже стоят, иди дальше.

### Шаг 3. Node.js
1. Открой https://nodejs.org, нажми большую зелёную кнопку **LTS** и скачай установщик `.pkg`.
2. Запусти его и нажимай «Продолжить» до конца.
3. Проверь в Терминале:
   ```bash
   node -v
   ```
   Должно появиться что-то вроде `v22.12.0`. Подходит версия 20 или новее.

### Шаг 4. Rust
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```
- Терминал спросит, как ставить. Нажми **Enter** (вариант 1, по умолчанию).
- В конце появится `Rust is installed now. Great!`
- Затем выполни, чтобы Терминал увидел Rust без перезапуска:
  ```bash
  source "$HOME/.cargo/env"
  ```
- Проверь:
  ```bash
  cargo -V
  ```
  Должно появиться `cargo 1.xx.x`.

### Шаг 5. Скачать код
Репозиторий закрытый, поэтому проще всего скачать архив через браузер, где ты уже залогинен:
1. Открой https://github.com/igorchepenko/inbox-mac. Если код ещё в pull request и не влит в `main`, сверху слева переключи ветку на `claude/inbox-release-fg4ct2`.
2. Нажми зелёную кнопку **Code**, затем **Download ZIP**.
3. В «Загрузках» дважды кликни архив. Появится папка `inbox-mac-…`.
4. В Терминале набери `cd ` (с пробелом в конце), **перетащи эту папку мышкой в окно Терминала** (путь вставится сам) и нажми Enter.

### Шаг 6. Установить зависимости
```bash
npm install
```
Через полминуты появится `added … packages`. Предупреждения со словом `warn` можно игнорировать.

### Шаг 7. Попробовать в режиме разработки (необязательно)
```bash
npm run app:dev
```
Первый запуск компилирует около 3–5 минут, бегут строки `Compiling …`. Потом откроется окно Inbox. Остановить: вернись в Терминал и нажми **Control + C**.
В этом режиме уведомления macOS могут не приходить, это ограничение режима разработки. В собранном приложении (шаг 8) они работают.

### Шаг 8. Собрать настоящее приложение
```bash
npm run app:build
```
Сборка идёт 3–7 минут. В конце появится строка `Finished 1 bundle at:` и путь к `Inbox.app`. Открой папку с ним:
```bash
open src-tauri/target/release/bundle/macos
```
В Finder перетащи **Inbox** в папку «Программы» и запусти. Метку из шага 6 первого способа снимать не нужно: приложение собрано на твоём Маке.

## Что должно появиться на экране

1. **Окно Inbox** с открытой главной: «Добрый день, Игорь», три кольца итогов и блоки ниже. Слева Главная, На разбор, Сегодня, Скоро, Архив, Календарь и проекты Работа, Команда, Дом.
2. **Иконка-молния в строке меню** справа вверху, рядом с часами. Клик левой кнопкой открывает быстрый ввод, правой даёт меню: «Записать задачу», «Открыть Inbox», «Настройки…», «Выйти из Inbox».
3. Нажми **⌥ Space** (Option + пробел) в любом приложении. По центру экрана появится карточка «Что нужно сделать?». Напиши название, при желании заметку, нажми **Enter**. Карточка исчезнет, ты вернёшься туда, где был, а задача появится в «На разбор».
4. Когда первый раз поставишь задаче время напоминания, macOS спросит «Inbox хочет присылать уведомления». Нажми **Разрешить**.

Закрытие окна крестиком не выключает Inbox: он остаётся в строке меню, чтобы работали ⌥Space и напоминания. Вернуть окно можно кликом по иконке в Dock или через меню иконки. Выйти полностью: **⌘Q** или «Выйти из Inbox».

### Чтобы Inbox запускался сам при включении Мака
Inbox → Настройки (**⌘,**) → Основные → включи «Открывать при входе в систему».

### Настройки
Открываются по **⌘,**, через меню Inbox → «Настройки…», шестерёнкой внизу левого меню или из меню иконки в строке меню. Разделы:
- **Основные**: начальный экран при запуске, запуск при входе в систему.
- **Внешний вид**: тема, шрифт (SF Pro, SF Rounded, New York, SF Mono), размер интерфейса.
- **Быстрый ввод**: своё сочетание вместо ⌥Space. Нажми на поле и затем клавиши; если сочетание занято, Inbox скажет об этом и оставит прежнее.
- **Уведомления**: включить или выключить, звук, пробное уведомление, утренняя сводка в выбранное время.
- **Меню**: какие списки показывать слева и с какими иконками.
- **Главная**: порядок и видимость блоков, рабочий день, сколько часов на задачи, цель в день, как к тебе обращаться.

## Как пользоваться

| Клавиша | Что делает |
|---|---|
| ⌥ Space | Быстрый ввод из любого приложения |
| N | Записать задачу внутри Inbox |
| ↑ ↓ | Выбрать задачу |
| Enter | «Разобрано»: задача уходит из «На разбор» в нужные списки |
| Space | Сделано / вернуть |
| 1 … 5 | Важность: от минимальной до максимальной |
| T | Поставить дату «Сегодня» |
| ⌘E | В карточке записи: показать дату, время, повтор и остальное |
| ⌘0 | Главная |
| ⌘1 … ⌘5 | Новые, Сегодня, Скоро, Архив, Календарь |
| ⌘6 | Все пространства карточками |
| ⌘P | Найти пространство и перейти |
| D W M, ← → | В календаре: день, неделя, месяц, листать |
| ⌘-клик, ⇧-клик | Выбрать несколько задач, подряд |
| ⌘A | Выбрать все в списке |
| ⌘/ | Окно со всеми сочетаниями |
| ⌘, | Настройки |
| Esc | Закрыть |

Мелочи, которые стоит знать:
- **Иконки пунктов меню** меняются кликом по самой иконке слева от названия.
- **Дата**: быстрые кнопки «Сегодня», «Завтра», «Пн», а кнопка «Другая» открывает календарь.
- **Напоминание**: поле пустое, пока не впишешь время. Набери часы, после двух цифр курсор сам перейдёт на минуты. Если набрать «9», получится «09». Enter сохраняет, Esc отменяет.
- Число в кольце рядом с заголовком показывает, сколько задач осталось разобрать или сделать (больше 99 будет «99+»).

Как задачи раскладываются по спискам:
- **На разбор**: всё, что записал и ещё не разобрал. Кольцо показывает, какую часть сегодняшнего входящего ты уже разобрал.
- **Сегодня**: разобранные задачи с датой сегодня или просроченные (дата краснеет), плюс сделанные сегодня. Кольцо показывает, сколько сделано.
- **Скоро**: задачи с будущей датой, сгруппированные по дням, и внизу группа «Без даты», чтобы разобранная задача без даты и проекта не потерялась.
- **Проекты**: незакрытые задачи проекта. «+ Новый проект» в боковой панели открывает окно: название, описание, цвет и иконка. Описание видно под заголовком проекта. Изменить или удалить проект: кнопка «Изменить» в его заголовке или клик по иконке проекта в боковой панели. При удалении задачи остаются, просто без проекта.
- **Календарь**: задачи с датой. Со временем стоят в сетке, без времени в строке «весь день». Перетащи плашку, чтобы сменить день или время, потяни за нижний край, чтобы изменить длительность.
- **Повторы**: когда отмечаешь повторяющуюся задачу сделанной, сразу появляется следующая. Если вернуть отметку, следующая исчезнет.
- **Архив**: сделанные задачи уходят сюда автоматически на следующий день или сразу кнопкой «В архив». Из архива задачу можно вернуть в работу.

## Известные ограничения первой версии

- **⌥Space может быть занят** другим приложением: Alfred, Raycast, ChatGPT, Claude. macOS при этом не сообщает об ошибке, сочетание просто достаётся первому. Проверить: Настройки → Быстрый ввод → «Проверить». Выход: сменить сочетание там же или отключить его в другом приложении. Быстрый ввод всегда доступен по клику на иконку в строке меню.
- **Spotlight показывает старую иконку**, если на диске остался старый `Inbox.app` (например, в «Загрузках» или в смонтированном .dmg). Удали лишние копии; если не помогло, перезапусти Dock командой `killall Dock` в Терминале.
- **Напоминания работают, пока Inbox запущен** (хотя бы в строке меню). Если Мак был выключен, пропущенные напоминания младше 12 часов придут при запуске, более старые гасятся молча.
- Время напоминания проверяется раз в 30 секунд, так что уведомление может прийти с задержкой до минуты.
- Резервная копия: просто скопируй файл `inbox.db` из папки, указанной в начале.

## Для разработчика

- **Стек**: Tauri 2 (Rust, системный WebView), React 19 + TypeScript, Vite, SQLite через `tauri-plugin-sql`. Горячая клавиша через `tauri-plugin-global-shortcut`, уведомления через `tauri-plugin-notification`, иконка в строке меню через tray API Tauri.
- **Окна**: `main` (основное) и `quick` (быстрый ввод, прозрачное, без рамки, поверх всех). Это одна сборка фронтенда, окно быстрого ввода открывается как `index.html?window=quick`.
- **Код**:
  - `src-tauri/src/lib.rs`: окна, ⌥Space, иконка в строке меню, миграции, поведение при закрытии.
  - `src-tauri/migrations/`: схема базы.
  - `src/home/`: главная. `src/CalendarView.tsx`, `src/calendar.ts`: календарь. `src/Board.tsx`, `src/boardOps.ts`: канбан, карточки, массовые действия. `src/Settings.tsx`, `src/HomeSettings.tsx`, `src/prefs.ts`: настройки. `src/extras.tsx`, `src/recurrence.ts`: поля расширенной задачи и повторы.
  - `src/db.ts`: запросы к SQLite. Сделанной задачу отмечают только `completeTask`, возвращают `reopenTask`: они ведут повторы. `src/views.ts`: какие задачи в каком списке. `src/App.tsx`: основное окно и клавиатура. `src/Quick.tsx`: окно ⌥Space. `src/reminders.ts`: уведомления. `src/styles.css`: цвета и вёрстка.
- **Проверка**: `npm run build` (TypeScript и сборка фронтенда), `cargo check` в `src-tauri`. GitHub Actions (`.github/workflows/build-macos.yml`) собирает universal `.dmg` на macOS.
- Спецификация и макет: в проекте Tasks (`inbox-app/spec.md`).
